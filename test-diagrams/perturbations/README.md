# Held-out parity perturbations

Each subdirectory belongs to one mechanism recorded under
`docs/parity-reviews/`. Every `.puml` must have a same-named `.svg` generated
by the Java PlantUML revision named in that mechanism's checker record.

These pairs are created by the checker after implementation and are permanent
tests of the no-oracle renderer. They are deliberately separate from the
fixed golden corpus used to measure T14 progress.
